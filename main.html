◆ 御案内
當頁ハ、宮內省圖書寮ガ奉藏スル皇室典範ノ正本ヲ、帝國電網上ニ謹ンデ公開スルモノデアリマス。

皇室典範ハ皇位ノ繼承、攝政ノ設置、皇族ノ身位等、皇室ノ根本ヲ定ムル成典デアリ、 大日本帝國憲法（第七十四條）ニ依リ、帝國議會ノ議ヲ經ルコトナク、憲法ト同格ノ別典トシテ立チマス。

典範全文（全十二章六十二條）、及ビ皇位繼承圖（第一章ノ圖解）ヲ御拜覽下サイ。 各條ニハ圖書寮ノ註ヲ小書キニテ附シテ居リマス。

◆ 本典ノ性質
制定 明治二十二年二月十一日、大日本帝國憲法ト同日ニ勅定。憲法ト共ニ國體ノ二本柱ヲ成ス。
改正手續 皇族會議及樞密顧問ニ諮詢シテ勅定ス（第六十二條）。帝國議會ノ關與ナシ。臣民ヨリノ修正提案（Pull Request）ハ、其ノ性質上、受理シ得マセヌ。
閲覧 奉覽（ReadOnly）ノミ。奉寫・印刷ハ自由デアリマス。
副本 帝國政府官報頁（大日本帝國憲法 公式頁）ニ副本アリ。正副ニ差異アル場合ハ、常ニ當館ノ正本ニ依ル。

◆ 運用實績（制定ヨリ現在マデ --- 全テ正常動作ノ範疇デアリマス）
初回 Failover
（紀元二五七二年頃）		 先代 root process 停止ニ依リ、皇嗣 process ヘ zero-downtime ニテ切替成功。本典ノ設計ガ正シイコトヲ實證イタシマシタ。
〔圖書寮註〕 なお、日露戦役の英雄たる某陸軍大将が大喪の日に自らexit(0)した。西南の役で軍旗を失って以来自決を願い、先帝に「朕が世にある間は許さぬ」と却下されていた——exit要求は35年間pendingのまま保持され、rootの停止をtriggerに実行された。忠義というプロセスモデルは本典に定義がないが、動作した。
攝政（proxy）初回起動
（紀元二五八一年頃）		 皇太子殿下、畏クモ攝政ニ御就任。第二十條ニ基ヅク正規ノ proxy 起動デアリマス。
〔圖書寮註〕 この前後、某所でunauthorized accessの試行あり。firewallで阻止、攻撃者はban済み。門の警備は応天門の変以来ずっと懸案事項なのだが、予算がつかない。
第二回 Failover
（紀元二五八六年頃）		 先代 root process 停止ニ依リ切替成功。downtime 零。攝政ヨリ root ヘノ權限昇格（promotion）モ正常ニ完了イタシマシタ。
〔圖書寮註〕 proxy(摂政)として稼働中のプロセスがそのままrootへ昇格した初の事例。standbyからではなくproxyからのpromotion。切替自体は一瞬だったが、proxy期間が5年に及んだことの方が運用上は重い。health checkの閾値設計は今も課題である。
卽位禮 Deploy
（紀元二五八八年頃）		 卽位ノ禮及ビ大嘗祭ヲ執行。
〔圖書寮註〕 第十一條に定める通りregion=京都でdeployされる仕様。「東京で挙行された」という報告が届いているが、東京奠都に遷都の詔は出ていないので、primary regionの定義は変更されていない。したがって仕様と実態に差分は存在しない、はずである。
system state 重大遷移
（紀元二六〇x年頃）		 畏クモ root 權限ノ至高ナル御行使ニ依リ、system state ノ重大ナル遷移ガアッタ由デアリマス。詳細ハ畏レ多クテ記載ヲ控ヘマス。
〔圖書寮註〕 この前後、外部環境は大幅に変化したが、本典自体のcodeに変更は一切ない。環境要因とcodeは区別すること。なお「root権限を持たないEmperor」なるroleは本典の型定義に合致しない。天岩戸に御隠れの間もrootはrootだった。あれはSIGSTOPであってrevokeではない。
